# 100 Days of Data Engineering Challenge

> Building practical Data Engineering skills from foundations to a portfolio-ready capstone — one day at a time.

This challenge is designed for **beginner-to-intermediate** learners. Over 100 days, you will build hands-on skills in Python, SQL, data pipelines, orchestration, big data, cloud (AWS), and streaming.

**Progress:** `0 / 100` days completed

---

## Challenge at a Glance

| Item              | Details                          |
|-------------------|----------------------------------|
| Duration          | 100 Days                         |
| Level             | Beginner → Intermediate          |
| Approach          | Theory + Hands-on Coding         |
| Daily Time        | ~2–2.5 hours                     |
| Breakdown         | 30-45 min theory + 60-90 min code + 15-20 min notes/GitHub |

## Challenge Guidelines

1. Read the objective and theory first, then write the code yourself.
2. Keep notes in your own words and commit daily.
3. Complete a mini project at the end of each phase.
4. Share progress or key learnings every 3–5 days.
5. If you miss a day, catch up — do not skip topics.
6. Each day’s folder should contain code, notes, and run instructions.
